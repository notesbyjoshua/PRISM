# PDIDB–GMDB conditional distributional consistency plan

Declared on November 9, 2026 after inspecting schema, labels, metadata coverage and QC counts, before computing fidelity metrics. This is a targeted secondary analysis; the primary study remains PRISM_120_20261028.

## Sources and matching

Use the frozen 1,845-record GMDB selection (one image per recorded patient, age 3 <= age < 10), 1,563 QC-passing PDIDB rows from 1,727 extracted rows, and the same 3,409-path FairFace reference. Require the exact ordered 120-feature schema, FaceKit commit, extractor checksum and landmark-model checksum. Reject nonfinite accepted features, repeated recorded GMDB patients, inconsistent QC or any synthetic primary rows. No extraction or primary test is rerun.

The explicit label crosswalk is reviewed against current cohort labels and internal syndrome names, with exact-name equivalence only. Nine labels have unambiguous counterparts. PDIDB's generic 22q11.2 deletion label is excluded: DiGeorge and distal-deletion GMDB labels do not establish equivalent ascertainment. No fuzzy matching, inferred source-patient linkage or merged syndrome subclasses. Newly encountered, unmatched or multiply mapped labels remain excluded. Clinical confirmation of broad cohort definitions remains a mentor review item.

Report QC counts and metadata missingness by source and syndrome. Inspect age_range, gender, race, model and verification rather than assuming coverage. No age imputation. An age-matched sensitivity runs only when recorded age metadata supports an unambiguous 3–9 selection; otherwise it is unavailable. Audit exact image-hash duplication, without publishing hashes or claiming identity independence.

## Estimands and conventions

Descriptive support requires at least 10 observations in both sources. Smaller/unmatched cohorts appear only in the eligibility audit, without feature statistics. The primary 48-syndrome set and 5,760-test BH family never change. Feature-level aggregate exports follow the existing aggregate-only policy and this minimum support; no individual values, extrema, IDs, photos, landmarks, crosswalks between people or synthetic bytes are released.

For every supported syndrome and feature report n, missingness, mean, sample SD (ddof=1), median, Q1 and Q3, synthetic-minus-real mean/median shift, shift divided by real SD, sample variance ratio and one-dimensional empirical Wasserstein distance (actual feature units and divided by real SD). Near-zero SD means <= 1e-12 in feature units. Such scaled values are undefined (blank), with explicit flags; sample n < 2 also makes SD undefined. Wasserstein includes finite-sample sampling variation and has no equivalence threshold.

Compare each real/synthetic group to the identical fixed reference using Hedges' g = (group mean − reference mean) / pooled sample SD × [1 − 3/(4(n_group+n_reference)−9)]. Also report each mean contrast divided by the same fixed reference sample SD; this removes group-variance differences from the scaling. Summarize Pearson/Spearman correlations only over finite nonconstant profiles, sign agreement (zero is its own sign), sign reversals (strictly opposite signs), median absolute effect difference and largest discrepancies. Report direction agreement additionally for |real g| >= 0.2 to expose unstable near-zero signs. No p-values, synthetic BH discoveries, diagnostic accuracy, equivalence claims or inferential confidence intervals.

Syndrome summaries give the median absolute real-SD-scaled mean shift, median variance ratio, fraction of defined features with variance ratio < 1, direction agreement and effect-profile correlation. These correlated features are not independent biological replicates. Existing frozen reference-correlation clusters supply an optional equal-cluster-weighted descriptive summary. Across-syndrome Spearman coefficients against available age-restricted GMDB n are descriptive only (at least 5 supported syndromes); these are not generator training counts or evidence of a training-size effect.

Pool model tags only to describe the observed released PDIDB mixture, with its empirical tag proportions, never as independent generators. Repeat all supported comparisons separately by model tag. Add separate within-source 1st/99th percentile winsorization (linear quantiles, all observations retained) as a heavy-tail sensitivity. Unwinsorized results remain the principal descriptive estimates. Do not infer ages, combine real/synthetic sample n, or resample individual repeated real photographs. No intervals are needed in this pass, so no bootstrap or generator-level uncertainty is claimed. Computation is deterministic; reserve seed 20261109 for any future explicitly declared Monte Carlo extension.
