# Active FaceKit statistical study

The validated study uses 120 FaceKit measurements, 48 primary syndrome cohorts and 5,760 primary tests, with 955 global-BH associations. The disease pool has 1,845 recorded patients and the expanded FairFace reference has 3,409 image paths. Synthetic PDIDB is excluded from real-patient inference. All exported results are aggregate. Concordance points are descriptive; its biased bootstrap uncertainty is excluded. See publication/PI_REVIEW.md before release.
