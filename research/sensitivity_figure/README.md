# Aggregate-only three-panel sensitivity figure

```sh
.venv/bin/python research/sensitivity_figure/generate_prism_sensitivity_figure.py --panel all
.venv/bin/python -m pytest research/sensitivity_figure/tests -q
```

The released figures, caption, four-row plotting CSV and provenance are in [`results_20261117/`](results_20261117/). The default `--comparison-source released` uses its pinned category-level input snapshot, so figure reproduction needs no private diagnostic files. To read the completed local diagnostic instead, add `--comparison-source private`; incomplete, changed or unverified private inputs fail rather than falling back to the snapshot. Rendering continues to write only to ignored `local_review/`, leaving the released snapshot intact.

Modes `composite`, `a`, `b`, and `c` independently render only the requested figure. `all` writes the composite plus three standalone panels. All figure files are PNG at 300 DPI and vector PDF/SVG, under verified ignored `local_review/sensitivity_summary_figure/`. A full caption and `figure_manifest.json` accompany them. To update only Panel C and the composite, preserving the standalone A/B files, run `--panel c` followed by `--panel composite`.

The original numerical input is `research/race_stratified_sensitivity_results_20261115/summary.json`. Updated Panel C and the composite additionally use either the pinned released aggregate snapshot or, in private mode, `local_review/reference_stability_diagnostic/reference_size_ladder_summary.csv`, its `source_and_execution_manifest.json`, and `verification_report.json`. For private inputs the diagnostic must be completed, its verification must pass, and aggregate and verification hashes must match its manifest. The released snapshot contains only four category-level summary rows and the reference-size plan, with the original diagnostic hashes retained for provenance. Study IDs, correction family, repetitions, original allocations, stability rule, original counts and discovery denominators must agree. No images, patient rows, per-feature tables, old pooled sensitivities or inference implementations are read. The supplied companion script was absent, so the specification was implemented directly. Both the original summary and released plotting input have pinned SHA256 hashes; changed or missing fields require explicit revalidation. Additional subgroup/global consistency checks protect denominators, overlaps, permutation counts/resolution, reference-variation status and zero conservative MC discoveries.

Panel C preserves the original African/Asian bars and adds the largest paired ladder allocation with reference selection varying in both categories. Selection uses reference sizes, never observed stability outcomes. Both displayed experiments use 1,000 without-replacement draws and the same original discovery denominators. The ≥80% global-q recurrence and ≥95% g-sign rule is the supplied definition and is checked against the diagnostic plan. European references remain fixed and are omitted from bars. Deterministic full-pool results and the separate with-replacement bootstrap estimate different quantities and are not mixed into this comparison. Joint reference-size changes can alter global BH competition, and near-full subsets reduce finite-pool selection variation; improved recurrence is not independent replication or clinical validation. `panel_C_reference_comparison_values.csv` records every displayed count, denominator and allocation. Original C/composite files and their caption/manifest are preserved once in `archive_original_panel_C/`.

Panel B distinguishes same-direction overlap from other empirical discoveries and prominently attaches the zero simultaneous-MC-upper-bound caveat. Panel A explicitly limits support to 2,760 of 9,600 planned hypotheses and does not claim to test cross-source effects.

The script checks text bounds, input hashes and source/checkout preservation. Visual QA additionally reviews spacing and legend/footnote separation at reading size. Tests use the public summary, released plotting counts and synthetic ladder counts, including an allocation with lower stability than a smaller allocation, to verify selection by size and rejection of incompatible inputs. No patient-data fixtures or inference reruns are involved. The authorized release contains category-level figures and plotting aggregates only; patient records, detailed syndrome/feature results, diagnostic checkpoints and local archives remain ignored. No manuscript, selector, source dataset, baseline result or sensitivity computation is changed.
